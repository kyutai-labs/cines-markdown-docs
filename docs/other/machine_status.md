# Machine status

If the red curve is at zero the machine is down. If there is no `attente`, the machine is in maintenance or down. Else the system is operational.

The small dips is activity can be explained by the SLURM scheduler making *space* for larger job to start.

**Note**

The `attente conditionée` area represents the amount of node pending due to dependencies on other job (notably). The `attente de ressource` area represents the pending jobs waiting for resources (sort of backlog).
